## Каталог фільмів
## Опис проєкту

Це простий застосунок, який дозволяє шукати фільми через OMDb API, переглядати коротку інформацію про них та додавати вибрані фільми у власний каталог.

## Основні можливості

- пошук фільмів за назвою;
- виведення назви, року, типу та постера фільму;
- додавання фільму у власний каталог;
- видалення фільму з каталогу;
- збереження каталогу у браузері за допомогою localStorage.
- отримання даних через OMDb API;

## Приклад використання

1. Відкрити файл "index.html" у браузері.
2. У полі пошуку ввести назву фільму, наприклад "Hulk".
3. Натиснути кнопку "Шукати".
